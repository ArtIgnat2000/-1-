# Проект: Расписание 2 «В»

Короткое руководство по проекту и локальному запуску.

## Структура

Проект состоит из двух слоёв.

**1) Расписание и питание** — страницы на общих `style.css` и `script.js`:

- `index.htm` — расписание уроков по дням недели.
- `meal.htm` — расписание питания.
- `style.css` — общие стили для `index.htm` и `meal.htm`.
- `script.js` — общий JS: переключение дней, загрузка `schedule.json`, дата в шапке.
- `schedule.json` — данные уроков (используется на `index.htm`).

**2) Каникулы** — страница перенесена из проекта `RaspisCanicyl` (образец, v2.2.0)
и полностью строится из данных:

- `holidays.htm` — календарь каникул на 2026/2027 (шапка, обратный отсчёт, периоды, месяцы).
- `css/style.css` — стили только для `holidays.htm`.
- `js/data.js` — справочники и утилиты (дни недели, месяцы, статус дня).
- `js/calendar.js` — генерация сетки месяцев, карточек периодов и обратного отсчёта.
- `data/holidays.json` — единственный источник данных о каникулах.

Доп. каникулы 1 класса помечены в данных флагом `"optional": true` — в календаре они
подсвечиваются голубым цветом (`vac-opt`) и вынесены отдельной строкой легенды
«Каникулы 1 класса».

## Как менять каникулы

Всё содержимое страницы берётся из `data/holidays.json`:

- `systems` / `vacations` — периоды каникул: `name`, `emoji`, `start`, `end`, при необходимости `optional: true`;
- `publicHolidays` — праздничные дни (красные), `specialDays` — особые дни (точка в ячейке);
- `workdays` — учебные субботы, `lastSchoolDay` — последний учебный день;
- `yearStart` / `yearEnd` — рамки календарной сетки (месяцы строятся автоматически).

После правки JSON перезагрузите страницу — счётчик периодов, карточки, обратный отсчёт
и календарь пересчитаются сами. HTML и CSS менять не нужно.

## Локальный запуск

Для страницы каникул нужен HTTP-сервер: календарь читает `data/holidays.json` через `fetch`,
поэтому при открытии файла двойным кликом (`file://`) вместо календаря появится
предупреждение «⚠️ Не удалось загрузить data/holidays.json».

```powershell
# из корня проекта
python -m http.server 8000
```

Затем откройте в браузере:

- `http://localhost:8000/index.htm` — расписание;
- `http://localhost:8000/meal.htm` — питание (эти две страницы работают и без сервера);
- `http://localhost:8000/holidays.htm` — каникулы.

## Навигация

Нижний док на странице каникул ведёт на сайты обновлённого семейства (как в образце):
`scool_shedule2026` (Уроки), `meal-schedule` (Еда), `DopSchedule` (Доп).
Если нужно, чтобы кнопки вели на локальные `index.htm` и `meal.htm` — достаточно поменять
`href` в блоке `<nav class="dock glass">` в `holidays.htm`.

## Изменения и примечания

- Все стили и скрипты вынесены в отдельные файлы, чтобы избежать дублирования.
- JS навешивает обработчики после загрузки DOM (используется `DOMContentLoaded`).
- Кнопки переключения дней используют `data-day="..."`, а не inline `onclick`.
- Страница каникул ничего не рисует вручную: месяцы, классы дней, легенда и подписи
  рассчитываются из JSON, поэтому даты физически не могут разойтись с данными.

## Деплой на GitHub Pages

Сайт публикуется из ветки `main` (корень репозитория), сборка не требуется:
`Settings → Pages → Branch: main, Folder: / (root)`.

- `https://artignat2000.github.io/-1-/index.htm` — расписание;
- `https://artignat2000.github.io/-1-/meal.htm` — питание;
- `https://artignat2000.github.io/-1-/holidays.htm` — каникулы.

Каталоги `css/`, `js/`, `data/` публикуются как есть (Jekyll их не трогает),
поэтому `holidays.htm` работает на Pages так же, как на локальном сервере.
